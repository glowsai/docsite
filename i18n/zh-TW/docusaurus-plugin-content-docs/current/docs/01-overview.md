# 概述

歡迎使用 [**Glows.ai**](https://glows.ai/)，這是一個一站式 AI 平台，能幫助您輕鬆應對 AI 訓練&推理、大規模數據處理和多節點協作等需求。本教學將帶領您快速熟悉平台的核心功能與進階操作，讓您靈活創建符合需求的工具與服務。

---

## **平台亮點**

1. **算力管理**  
   快速創建與監控實例，高效配置 GPU 和 CPU 資源，輕鬆應對多樣化需求。
2. **開箱即用**  
   應有盡有的主流工具鏡像，開啟實例即可選用，讓你免去繁瑣的安裝步驟。
3. **數據安全**  
   利用快照與備份功能簡化工作流程，減少誤刪除風險。
4. **儲存優化**  
   管理儲存空間，提升資源使用效率。
5. **成本透明**  
   清晰的帳單系統，幫助您掌握支出，配置最低成本。
6. **Glows.ai Team**  
   專為開發者團隊設計的資源共享管理平台。

---

## **您將學到**

在本教學中，您將探索以下核心功能：

- **快速開始**：註冊帳號並完成基礎設定，快速熟悉平台。
- **創建新實例**：了解如何配置適合您專案需求的 GPU 和 CPU，量身打造最佳的運算系統。
- **管理實例**：管理您的所有實例，並監控執行狀態。
- **數據驅動**：自由上傳數據，並彈性配置給實例使用，了解如何在不同實例間管理資料。
- **快照功能**：透過即時實例快照與便捷的還原功能，減少重複的步驟，優化您的工作流程。
- **鏡像功能**：了解不同的機器類型提供的的多元鏡像，並上傳自定義的鏡像。
- **儲存管理**：靈活配置存儲空間中不同區塊，因應不同開發階段的存儲調度。
- **自動部署**：配置自動化的開關機流程，使您的機器不會因閒置而消耗預算。
- **Glows.ai Team**：打造一個讓團隊成員能迅速上手的算力管理環境，安全並有效率地分配共享資源。
- **叢集協作**：配置多節點 Mesh Clustering，實現高效協作與資源分配。
- **帳單系統**：查看帳戶餘額與詳細帳單資訊。
- **個人化設置**：調整使用者設定，打造良好的使用體驗。

完成教學後，您將能夠：
